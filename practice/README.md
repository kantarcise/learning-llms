# Coding and design practice

Keep a brief record of the problem, assumptions, initial approach, solution, complexity, edge cases, and mistakes. Attempt timed exercises without assistance before reviewing.

- Hash maps, heaps, binary search, graphs, and dynamic programming.
- Daily capacity and limited cluster switches.
- Expiring credits and historical balances.
- Versioned relationships and snapshot queries.

Design topics:

- GPU job scheduling.
- Document-conversion inference pipelines.
- Streaming model serving.
- An occasional unrelated distributed-system problem.
